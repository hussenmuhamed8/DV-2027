# DV Frame — استوديو صورة القرعة

مشروع ويب بالعربي والإنكليزي يفتح الكاميرا ويوجّه مكان الرأس والعينين والذقن، ويساعد بمراجعة الصورة وقصّها وتنزيلها **JPEG بقياس 600×600 وحجم لا يتجاوز 240,000 بايت**.

## المميزات

- تبديل عربي/إنكليزي مع تغيير الاتجاه وحفظ اللغة المفضلة، بدون فقدان الصورة الحالية.
- كاميرا مباشرة، زر كاميرا الجهاز، ورفع صورة.
- تعرّف محلي على الوجه يعمل بخلفية منفصلة عن الأزرار.
- تحديد يدوي لأعلى الشعر والعينين والذقن، مع تقريب وتحريك القص.
- تقييم تقديري للإضاءة والخلفية والاستقامة ودقة الصورة.
- الصورة لا تنرفع للسيرفر. لا يحتاج API أو حسابات أو اشتراكات.

## التشغيل بالحاسبة

ثبّت Node.js إصدار 22 أو أحدث، وافتح الطرفية داخل مجلد المشروع:

```sh
npm run setup
npm run dev
```

افتح `http://localhost:4173`. ما تحتاج `npm install` لأن المشروع ما يعتمد على حزم npm. الأمر الأول ينزّل ملفات التعرّف المثبتة بالإصدار ويتحقق من بصمتها، أو يتحقق من الملفات إذا موجودة مسبقاً.

على الهاتف استخدم رابط HTTPS. فتح ملف HTML مباشرة أو عنوان شبكة محلية بـHTTP قد يمنع الكاميرا.

## الفحص والتجهيز

```sh
npm run check
```

يجهّز مجلد `dist` ويشغّل الاختبارات. الاختبارات تحاكي الكاميرا؛ لازم تختبر الكاميرا الفعلية على الأجهزة المستهدفة قبل إطلاق المشروع للناس.

## الرفع على GitHub

1. أنشئ مستودعاً باسم `DV-2027`.
2. ارفع ملفات المشروع إلى المستودع، باستثناء `public/` وملفات الصور الشخصية. يمكن توليد ملفات النماذج باستخدام `npm run setup`.
3. للتشغيل كموقع: من **Settings → Pages** اختَر **GitHub Actions**.
4. من **Actions → Deploy GitHub Pages → Run workflow** شغّل النشر.

رفع الكود يختلف عن نشر الموقع. ملف CI يفحص الكود عند كل push؛ نشر الموقع يدوي. قد تختلف إتاحة Pages حسب نوع الحساب وخصوصية المستودع.

## تعديل المشروع

عدّل الملفات داخل `src/` ثم شغّل `npm run check`. لا تعدّل ملفات `dist/` مباشرة؛ هي نتيجة البناء. النصوص الإنكليزية داخل `src/translations.json`، والنص العربي هو مفتاح الترجمة.

النسخة المضغوطة تتضمن الملفات المولّدة والنماذج حتى تقدر تشغّلها مباشرة. راجع README.md لتفاصيل البنية والتطوير.

## حدود الفحص

هذا مساعد مستقل، مو جهة رسمية ولا ضمان قبول. أعلى الشعر يحتاج تحديد يدوي. فحص الخلفية يقيس الأطراف فقط؛ وفحص الضوء تقريبي. لازم تراجع النظارات، عمر الصورة، التعديل على الملامح، الخلفية كلها ووضوح العينين بنفسك. ممكن تنزّل نسخة للمراجعة رغم وجود ملاحظات.

راجع تعليمات دورة القرعة الفعلية قبل تقديم الصورة. ما تم اختيار رخصة مفتوحة لكود المشروع بعد؛ صاحب المستودع يختارها إذا يريد ينشره كمشروع مفتوح المصدر.
