# DV Frame

**تطبيق لإعداد صور قرعة الهجرة الأمريكية بواجهتين عربية وإنجليزية.**

يوفّر DV Frame إرشادات أثناء التصوير، وأدوات لضبط تكوين الصورة، وتصديرها بصيغة JPEG مباشرة من المتصفح. تُعالج الصور محلياً على الجهاز.

[English](README.md)

## المزايا

- **تصوير موجّه:** معاينة مباشرة مع خطوط إرشادية للرأس والعينين والذقن، وإمكانية استخدام كاميرا الجهاز أو اختيار صورة.
- **ضبط تكوين الصورة:** تحريك منطقة القص والتقريب وتحديد أعلى الشعر والعينين والذقن يدوياً.
- **مراجعة الصورة:** تقدير حجم الرأس ومستوى العينين والوضعية والإضاءة وتجانس الخلفية ودقة الصورة الأصلية.
- **كشف الوجه محلياً:** معالجة معالم الوجه باستخدام MediaPipe في عملية خلفية.
- **واجهة ثنائية اللغة:** دعم العربية والإنجليزية واتجاه العرض المناسب لكل لغة.
- **تصدير JPEG:** صورة بقياس 600 × 600 بكسل وحجم لا يتجاوز 240,000 بايت، دون الخطوط الإرشادية.

## الاستخدام

1. التقاط صورة أو اختيار صورة موجودة على الجهاز.
2. ضبط القص وتأكيد مواضع أعلى الشعر والعينين والذقن.
3. مراجعة نتائج الفحص وتأكيد شروط الصورة.
4. تنزيل ملف JPEG.

يقتصر تعديل الصورة على القص وتغيير الحجم، دون تغيير ملامح الوجه أو استبدال الخلفية. يتطلب التصوير إذن الوصول إلى الكاميرا وبيئة متصفح آمنة.

## الخصوصية

تُعالج الصور داخل المتصفح. لا يرفع التطبيق الصور أو يحفظها بشكل دائم، ولا يتطلب حساباً أو يتضمن أدوات تحليل استخدام. يُحفظ تفضيل اللغة فقط محلياً. تتلقى خدمة الاستضافة طلبات تحميل ملفات التطبيق والنماذج المعتادة.

## نطاق الفحص وحدوده

DV Frame أداة مساعدة مستقلة وغير تابعة للحكومة الأمريكية. نتائج الفحص تقديرية ولا تمثل اعتماداً رسمياً. يعتمد فحص الخلفية على أطراف الصورة، ويتطلب موضع أعلى الشعر تأكيداً يدوياً. يجب مراجعة عمر الصورة والتعديلات السابقة والنظارات وتعابير الوجه والخلفية كاملة بصرياً.

إمكانية تصدير الملف لا تعني استيفاء جميع شروط التقديم. يُرجع إلى التعليمات الرسمية لدورة القرعة المعنية لتحديد متطلبات قبول الصورة.

- [متطلبات الصور الرسمية](https://travel.state.gov/content/travel/en/us-visas/visa-information-resources/photos.html)
- [دليل تكوين الصورة](https://travel.state.gov/content/travel/en/us-visas/visa-information-resources/photos/photo-composition-template.html)
- [تعليمات برنامج قرعة الهجرة](https://travel.state.gov/content/travel/en/us-visas/immigrate/diversity-visa-program-entry/diversity-visa-instructions.html)

## التقنيات

يعتمد التطبيق على JavaScript وHTML وCSS وCanvas وWeb Workers وMediaPipe Tasks Vision. توفّر سكربتات Node.js التحقق من ملفات النماذج وبناء التطبيق والفحوص الآلية. إصدارات ملفات التشغيل والنماذج مثبّتة في `assets.lock.json`.
